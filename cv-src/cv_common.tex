\section{Research Experience}
\position{Graduate Research Assistant}{Aug 2025 -- Present}
{Dept.\ of Computer Science, Tuskegee University \quad\textbullet\quad Advisor: Dr.\ Mohammad Arafatur Rahman}
\begin{itemize}
  \item Model sensor-layer attacks (replay, false-data injection, Gaussian observation corruption) on
  learning-based CPS controllers and build detection-and-recovery defenses that keep closed-loop control
  stable in simulation.
  \item Built cloud-controlled reinforcement-learning CartPole testbeds (Q-learning, DQN, PPO); showed that
  corrupting a single critical state variable (pole angle) degrades control as severely as corrupting the full
  state, so defenses must be targeted rather than uniform [2]. Developed LSTM-based integrity-attack
  detection for cloud-based CPS [1].
  \item Paired a PPO controller with an LSTM-autoencoder anomaly detector and a blockchain-anchored
  recovery mechanism that deterministically detects replay attacks and restores the most recent verified
  clean state [3].
  \item Designed reconstruction-assisted recovery for artificial-pancreas RL control under CGM sensor attacks,
  combining a residual-LSTM state reconstructor with a safety shield; evaluated glucose-control and risk
  metrics in the simglucose simulator [4].
  \item Evaluated classical and quantum RL controllers under meal-information uncertainty in
  artificial-pancreas systems [5]; contributed to an auditable evidence-ranking framework for AI-assisted
  NMR metabolomics [6].
\end{itemize}
